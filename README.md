# Projet Computer Vision

Projet de vision par ordinateur réalisé en Python.

L'objectif du projet est de traiter automatiquement des formulaires pris en photo, notamment en détectant les cases cochées et les zones de signature.

Le dataset ainsi que les fichiers Excel ne sont pas inclus dans ce dépôt en raison de leur taille. Seul le code source est fourni.

## Technologies

- Python
- NumPy
- scikit-image (skimage)

## Lancer le projet

```bash
python main.py
```

## Fonctionnalités

- Détection automatique des formulaires
- Détection des cases cochées
- Détection des signatures
- Traitement automatisé des données extraites
